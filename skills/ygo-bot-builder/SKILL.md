# 构建游戏王人机

## 锁定输入和交付范围

1. 固定 YDK、主副额外卡号与数量、卡库、卡片 Lua、OCGCore 和 SRVPro2 版本。用 ygo-db 核对卡文，逐卡比对实际运行卡库、脚本和异画卡号。牌表能通过入房检查时也要验证核心卡确实会发效果。
2. 为新构筑使用独立牌表、策略入口和可选模型。把抢占命令、规则版可玩、完整策略和训练版分阶段验收。只占命令时先验证隐藏点名、入房、开局和核心牌有效出牌。
3. 将用户给出的路线、互动时序和斩杀条件写成卡组策略与固定回归局面。亚马逊首版见 [构筑策略](references/amazoness.md)，新构筑默认共用 [终场评分](references/endboard-scoring.md)。

## 规则基线与离线宽搜

1. 按效果编号建立策略，记录区域、阶段、触发窗口、目标、代价、共享次数、自肃及结算后变化。先覆盖启动、补点、低停、后场盖放、对手回合响应和战阶。常规窗口也要有明确的拒绝条件。引擎提示只代表合法候选。
2. 先攻用真实引擎搜短路线、可落地终场和备用路线。每条分支保留已用通召、效果次数、公开状态、手牌、素材、站位和锁定。宽搜枚举引擎给出的合法动作、连锁、对象、选项和素材。用终场分指导扩展，留出分支预算给不同资源结构和手坑后的低停路线。
3. 后攻覆盖空场、不同攻守与表示、保护、单前场、多前场和有后场的代表局面。对手阻抗可用实际牌与固定动作窗口抽样。运行时只输入公开信息和自己的可见资源。离线固定牌序仅用于复现，禁止把对手隐藏手牌或未来抽牌传给策略。
4. 路线排序依次比较确定斩杀、解掉的有效威胁、实际伤害、主二可兑现的场值和续航。战斗搜索要考虑攻击顺序、攻击目标、表示、保护、伤害步骤效果、直击条件、可攻击次数和攻击自肃。入战前、连锁结算后、每次战况变化后重算。发现斩杀失效时按后续优先级处理，主二承接真实剩余资源。
5. 用每个局面内引擎实际重放通过的结算结果做标注。可选训练轻量 CPU 排序器，训练与留出按整手、局面和随机种子隔离。训练只重排合法候选，保留限时规则和超时兜底。按真实对局结果决定是否启用权重。
6. 复用仓库的双子 [独立搜索及回归](../../ygo-windbot/tests/README.md)、[后攻候选排序](../../ygo-windbot/experiment/README.md) 和大贤者 [搜索策略与实盘接入](../../ygo-windbot/magistus/README.md)。使用各卡组自己的评分映射、规则、数据和模型。

## 统一决策入口

- 为牌组明确猜拳胜出后的先后攻偏好，并在房间协议里验证实际开局座位。亚马逊偏好先攻。
- 依次检查引擎合法选项、共用规则和牌组条件。标准路线和模型只能在通过这些检查的选项里选。召唤表示、效果已被无效、自肃和可确认的斩杀保护均属于共用约束。
- 标准路线仅匹配已验证的效果、时点和选择项。遇到额外的可选发动或无法匹配的提示，交给当前局面的规则，保留明确的跳过选项。受到阻抗后，从实际结算状态重新判断。
- 回归同时验证该发与该跳过的局面。至少覆盖标准路线、普通决策和模型权重的入口。区分逐卡发动条件测试、引擎实际回放和线上版本验证。

## 交阻抗与续航

- 先判断对手动作会带来什么、当前响应能否阻止实际威胁。评估目标是否有效、效果是否已被覆盖、是否该等关键窗口、交完还有哪些独立阻抗。区分效果擦、康发动、康效果和只去除实体。
- 同等收益先用场上的可兑现阻抗，保留手坑，尤其避免过早交陨石清掉己方盘面。对手逼近斩杀、关键效果即将落地或先用前场会错过窗口时，按实际生存和干扰收益改序。
- 对手追加新的连锁链接、进入新连锁或消耗代价后，重查还剩哪些可用阻抗。按对应连锁链接和目标判断覆盖范围。只去除实体通常不会取消它已发动的效果，也要避免提前移走己方正在无效的目标。
- 轮到自己优先保斩杀和即时做场。对方回合保护生存、兑现阻抗后，争取低代价续航。盖牌根据可用区域、同名限制、手发条件和后续自肃判断。

- 防陨石策略由各构筑独立维护。按该构筑的真实对局窗口验证避让、保护和结算后续展。

## 召唤表示

- 先按引擎给出的合法表示选择。陨石衍生物和原本攻击力为 0 的怪兽，在允许时优先表侧守备。
- 己方第 1 回合主一和己方主二，攻击力低于 2000 或不高于守备力时优先表侧守备，其余优先表侧攻击。其他时点默认优先表侧攻击；召唤效果的表示限制由引擎执行。
- 在标准路线、规则兜底和模型排序之前处理表示提示。离线生成新样本时使用同一规则。用同一张怪兽分别核验标准路线、随机起手和引擎强制表示。

## 验收与部署

- 固定种子分别验证无阻展开、典型手坑、结算后重新规划、先场后手坑、必交与应跳过的效果、斩杀实伤、非斩杀解场和主二。记录牌表及版本指纹、终场分细项、参考路线、响应延迟和首个分歧点。宽搜的最高已验证分是对照下界，搜索未覆盖的路线保留为未知。
- 候选版本和规则版对拍。可斩局实际斩杀率、非斩杀解场与伤害、主二续展、超时和非法输入都纳入门槛。先通过隔离服点名对局，再上线。
- SRVPro2 命令项使用专属名称和唯一 deck 键，隐藏点名设 `hidden: true`。从线上现有名单增量追加，确认运行时能解析对应执行器或路由。名单若在启动时读取，备份文件并在空闲时切换。检查服务健康、隐藏配置、点名入房与开局，准备回滚。涉及 WindBot 基线构建时读 [ygo-windbot](../ygo-windbot/SKILL.md)。
