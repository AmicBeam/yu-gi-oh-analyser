# 通用终场评分 v1

以一次合法、能独立兑现的常规阻抗为 1 分左右。以下是可由回放共同使用的初始权重。以效果本身的实际作用分类，卡名只用于定位效果。

| 效果 | 基准分 | 计分边界 |
| --- | ---: | --- |
| 炸卡 | 1.00 | 一次有效破坏。范围和目标限制进入可兑现性。 |
| 弹卡 | 1.00 | 一次有效返回。弹额外卡组怪兽通常比弹可重新部署的主卡组怪兽更难回补。 |
| 夺控制权、炸全怪 | 1.00 | 首版按一次去除，同一解场事件只计一次。 |
| 怪兽擦 | 1.00 | 令场上怪兽效果无效，取对象、持续时间和离场规避按结算判定。 |
| 三色擦 | 1.05 | 可覆盖怪兽、魔法和陷阱的效果无效。 |
| 怪兽康 | 1.00 | 无效怪兽效果的发动。 |
| 魔法陷阱康 | 1.00 | 覆盖魔法与陷阱。仅覆盖其中一类时初始为 0.80。 |
| 三色康 | 1.10 | 可在同一次数内覆盖怪兽、魔法与陷阱。 |
| 无效并破坏 | 对应无效分 + 0.30 | 破坏分只在能够破坏时加。单次响应只记一次基础分。 |
| 抽牌或有效抽滤 | 0.50／张 | 抽滤按结算后保留的新抽牌张数，旧废牌洗回后换来的新牌照计。 |
| 调度手坑 | 对应阻抗的固定分 | 做场通过检索、回收或布置新增可用阻抗时计分，与现场已有的同名共享次数合并。普通手坑从起手保留或随抽牌得到时只记录，盖放普通手坑也不加做场分。 |
| 限制或封锁 | 按具体限制指定固定分 | 有明确维持条件时，效果可用计固定分，条件缺失计 0。乔治的墓地怪兽封锁固定 1.00。 |
| 狮鹫封锁 | 0／2.00／2.30 | 按己方终场的连接箭头和额外怪兽区占用计分，见下文。 |

## 统一计算

1. 为每条效果记录来源、效果序号、结算类别、可用窗口、消费资源、共享次数、目标和前置条件。由实际结算区分康发动与无效效果，同一张卡有多效果就逐个标注。
2. 对当前终场使用固定分。资源、区域、窗口和效果次数齐备时按基准计，已知前置条件缺失计 0。实际演绎具体响应时，按当时的合法目标和结算再判断能否兑现。需要另开连锁的无效效果，若只无效且不破坏，基准分乘 0.7。其他需要另开连锁才能形成的阻抗乘 0.8。怪盗上镜的三色擦为 1.05 × 0.7 = 0.735，大蓝炸卡为 1.00 × 0.8 = 0.80。案例分开报告。
3. 做场时按终场的可用能力计分。目标可以在对手回合出现，剑圣能解放自己也满足代价。实战回放再检查具体顺序，并在消耗资源后重算。会用掉已有手牌时记录具体卡、用途和机会成本。同分优先保留可用手牌。某效果已经用于启动时，按实际结算核对去除是否发生。
4. 正常抽牌 0.50／张。刻不知的抽二折算 1.5 张即 0.75，已含跳过下次抽卡阶段的折损。锁龙蛇抽四后把三张原有废牌放回，四张新牌都留手，得 2.00。抽到普通手坑只计对应的抽牌分。
5. 输出 `interactions`、`draw`、`hand_spent`、`follow_up`，并记录前置条件、冲突和回放依据。比较己方场先看阻抗与已兑现抽牌，再比较已有手牌消耗和续航。在对手回合优先防斩杀和关键交互，再比较续航。

## 狮鹫封锁

- 狮鹫的封锁不可用，或己方连接箭头指向任一对方主怪兽区时，计 0。封锁可用且己方连接箭头均未指向对方主怪兽区时，计 2.00。若同时恰好占用一侧额外怪兽区，且己方没有箭头指向另一侧额外怪兽区，计 2.30。

## 算例

- 鲜花的三色康并破坏是 1.40，只能无效时按 1.10。同一回合只剩一次时无法按三种颜色分别累加。
- 带装备的乔治计魔陷康 1.00 和墓地怪兽封锁 1.00。无剩余装备时，两项按实际资源重算。先交魔陷康送掉最后一张装备后，不能再指望封住随后发动的墓地怪兽效果。
- 刻不知 0.75、乔治 2.00、鲜花 1.40、罗刹和救出剧各 1.00，共 6.15。可用剑圣通常在终场再加 1.00，共 7.15。若实战中罗刹只完成苏生，该次去除为 0。
