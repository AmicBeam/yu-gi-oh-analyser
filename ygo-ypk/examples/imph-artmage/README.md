按用户提供的两张卡图及补充要求制作；两张卡都只实现②，①不生效。卡图和显示卡文保留原图、原文。

| 卡名 | 临时卡号 | 本卡字段 |
| --- | --- | --- |
| 无垢奥艺之绊 神艺 | 100990045 | 奥艺 0x1e6、神艺 0x1cd |
| 神幻学都 奥艺 | 100990061 | 奥艺 0x1e6、神艺 0x1cd |

“奥艺”沿用现有“无垢大艺术／アルス＝マグナ”的字段 0x1e6；神艺 0x1cd、终刻 0x1d2、耀圣 0x1d8、狱神 0x1ce 均使用现有字段编号。数据库实际写入两张卡各自的双字段，不只是名称表。场地规则上属于神艺的文本由数据库字段落实。

## 安装

1. 将 imph2.ypk 放进 YGOPro / YGOPro2 的 expansions 目录。
2. 重启客户端，在卡组编辑器按卡名或上述临时卡号查找。
3. YGOMobile 用户在设置中确认实际游戏目录，将包放进该目录下的 expansions，并勾选“启用扩展卡包”。

联机对局需要对局所用内核／服务器以及相关客户端都加载这份扩展；仅本地安装无法让不支持自定义卡的公共服务器执行脚本。未来正式卡库收录后，可移除本包以避免重复卡名。

## 实现内容

- 无垢奥艺之绊 神艺：光属性／天使族／LINK-4／ATK 2500，箭头上、下、左、右；正规连接召唤需至少2只素材且包含奥艺或神艺怪兽。
- ②：自己主要阶段发动，按卡名每回合只能使用一次；从卡组选择奥艺／神艺／终刻／耀圣怪兽加入手牌或特殊召唤。前半成功后重新统计自己场上表侧怪兽的种族，至少3种且有可用怪兽区时，可从墓地或表侧除外状态特殊召唤1只怪兽；遵守苏生限制及王家长眠之谷等限制。
- 神幻学都 奥艺：场地魔法，可正常发动到场地区；②是场上起动效果。
- ②：自己墓地有狱神怪兽时，除外墓地1只融合／同调／超量怪兽作为代价，宣言奥艺连接怪兽卡名并从额外卡组特殊召唤。同一回合同名场地共享已宣言卡名记录，更换场地不能重复宣言，但可以宣言不同卡名。
- 场地②召出的怪兽不能作为连接素材；该特殊召唤不是连接召唤，不赋予正规召唤完成状态。
- 新 L4 接入“无垢大艺术-「黄昏之变幻」”①的联动：该永续魔法生效（自己场上同时存在狱神连接怪兽）时，②以快速效果发动；联动失效后恢复为起动效果。两种方式共享同一卡名每回合一次的次数，不会因转换重复使用。
- 新增测试覆盖：仅有永续魔法／仅有狱神连接怪兽时不转换；双方条件具备时转换；在对手回合实际连锁发动②；永续魔法在连锁中被旋风破坏后，L4仍正常处理，切回起动效果后同名卡也不能在同一回合重复发动。
- 两张新卡自身的①均未注册；所有发动选项和提示文字已写入 CDB。
