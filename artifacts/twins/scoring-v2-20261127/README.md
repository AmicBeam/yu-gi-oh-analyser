# 双子按新口径重训

防陨石在双子构筑内独立实现。第五次召唤窗口的镇魂棺接初诣和合影续展仍共用一分。通用口径只规定阻抗、抽牌和各类已定义封锁的记法。新评分器在千分之一分精度下分别给大蓝延迟炸卡 0.800、上镜延迟擦 0.735、强制断线基础三色康 1.100，正常抽牌 0.500。两种旧防陨路径、狮鹫三档和上镜精度已通过规则单测。

| 模块 | 训练规模 | 候选与验证 |
| --- | --- | --- |
| 先攻展开 | 28 手，697 对。随机搜索 24 手，引导实盘 4 手。 | [候选权重](first-turn-retrained/twins-branch-ranker.tsv)、[训练明细](first-turn-retrained/training-summary.json)、[12 局留出对拍](retrained-ab/report.json) |
| 后攻解场、斩杀和主二 | 45 个局面、4,500 次搜索尝试、1,454 对训练样本。45 条最佳路线全部完整重放核对。 | [候选权重](second-turn/second-turn-ranker.json)、[训练明细](second-turn/summary.json)、[留出标签对拍](second-turn/ab-offline.json)、[实际房间对拍](second-turn/ab-runtime.json) |

先攻留出与训练按五张起手完全隔离。候选在 12 局里的 11 局等分，小蓝吃陨石一局由规则版 8.435 降到 7.735，未通过晋级门槛。小蓝吃陨石的退分已[串行复现](retrained-ab-serial/report.json)。锁鸟蓝手串行复测的主阶段最长间隔为规则版 3072 ms、候选版 3094 ms，门槛为 3000 ms。后攻两版在 326 对留出动作上的排序正确率同为 62.58%，其中斩杀标签从 46/69 到 53/69，主二分标签从 61/108 到 58/108。实际房间的两组解场用例都进入主二并得 7.435 分，两版都能在 4,000 LP 用例的第 2 回合斩杀。

本轮产物用于离线实验。两个候选共用同一个做场评分器，分别按先攻终场与后攻斩杀、解场、伤害、主二终场的目标拟合。
