# 亚马逊效果发动审计

固定 40 主卡／15 额外。本表覆盖牌表全部 34 个不同卡号。决策只从 SRVPro2 或 OCGCore 当前给出的合法响应中选。引擎负责硬条件、每回合次数、素材与代价、自肃、种族和属性限制、被无效状态以及伤害步骤细则。策略另判断实际收益。[逐卡规则测试](effect-audit.test.cjs) 覆盖允许与拒绝用例。表内的实盘与全阶段引擎见证在训练归档里核对。

| 卡 | 发动条件与决策 |
| --- | --- |
| 原始生命态 尼比鲁 | 引擎给出第五只以后的合法窗口。对手有斩杀威胁时可优先交。通常先保留能交的剑圣、乔治、鲜花，并比较解放双方的场值。 |
| 亚马逊战士长 | 手牌起跳看引擎空场／纯本家约束。召唤盖放优先救出剧；战阶仍需要非本家攻击时跳过，主二可盖。 |
| 亚马逊格斗战士 | 非抽牌进手才起跳。落地盖救出剧、罗刹或三面镜，已有同名后场时调整。伤害计算的保护用于防战破或战伤，能打赢时保留。 |
| 鹰身女郎·魅惑之舞 | 场墓改名由引擎维护。主阶段手牌快效优先回手已被指定的己方地／风怪。诅咒师或救出剧连锁只在可保留融合素材或能免掉重复回手时考虑。落地检索按现有后场补缺。 |
| 圣王女 罗丝帕梅拉 | 对手回合缺粉碎且有可丢牌才考虑手牌换牌。落地盖放效果使用引擎提供的目标和当回合可发动状态。盖卡破坏保护持续适用。 |
| 亚马逊王女 | 场墓当女王。落地优先搜可用后场；攻击宣言的送墓调度只在补场收益成立且该攻击还值得执行时使用。 |
| 亚马逊诅咒师 | 落地检索优先可用补点。自己主阶段融合按手场有效素材，保留 C2 魅惑的分支。墓地交换攻击力用于改变战斗结果，避免给对方升攻。 |
| 屋敷童 | 引擎允许拦墓地相关效果，优先响应对手的有效连锁。 |
| 灰流丽 | 引擎允许拦从卡组调度，优先挡增殖的 G 和能推进对手展开的效果。 |
| 幽鬼兔 | 引擎允许时破坏仍有场值的实体。单前场只破坏而不能阻止威胁时可留手。 |
| 增殖的 G | 对手有特召进展时交，已经生效时保留同名，并让锁鸟等待。 |
| 小丑与锁鸟 | 对手检索后由引擎给窗口。己方已有增殖的 G 生效时跳过。 |
| 效果遮蒙者 | 对方主阶段针对仍在场、可无效的当前连锁怪兽，避免重复交阻抗。 |
| 增援 | 自己主阶段从卡组补可用战士，优先可展开的诅咒师、格斗战士或王女。 |
| 华丽的三面镜 | 检索魅惑；只有对方有场时的附加特召选择有效展开对象。墓地融合优先剑圣或能双击的女帝王。 |
| 亚马逊的叫声 | 默认检索，盖着罗刹且缺苏生目标时可送墓。墓地全打只在有多个可战破目标且战斗或剑圣抽牌有收益时采用。 |
| 罗刹之阵 | 有可苏生目标才有提示。两只夺控制、三只清怪，按实际结算选。只有一只敌怪且该怪已有有效响应时保留。空场续展沿战士长／格斗战士接救出剧。 |
| 无限泡影 | 空场手发、盖放发动与纵列效果由引擎核对。只对仍在场且可无效的当前怪兽响应，盖泡影优先于手牌擦。 |
| 圣王的粉碎 | 检索无效窗口，墓地有陷阱才可能额外破坏。一般留手，手发涉及暗／水／炎效果自肃时优先留给危险连锁。 |
| 亚马逊救出剧 | 合法时先特召再弹，优先对手威胁或和魅惑同目标的己方展开。避免和剑圣、罗刹抢唯一目标。墓地优先回收可起跳的格斗战士，或主阶段还有地／风回手目标时调度魅惑。 |
| 亚马逊女帝王 | 融合后拉可延续战斗的本家。以王女（场墓当女王）为素材满足双击时由引擎开放第二次攻击；其他本家保护由引擎持续适用。 |
| 亚马逊剑圣 | 融合落地调度；本家战破时抽；有效怪兽擦优先当前连锁目标。优先解放低价值怪，剑圣单独留场可解放自身。 |
| 鲜花女男爵 | 有效目标才用炸卡；关键对手效果才交康；站场康已经消耗且有收益的复活对象时考虑准备阶段回额外。 |
| 祭杖龙骑士 | 被特召时合法装备墓地龙骑兵团；送墓时优先装备乔治以开启封墓及魔陷康。 |
| 电磁虾 | 落地只在有值得炸的对手后场时付送墓。对方主阶段用自身 2 星和可配材料做有收益的加速同调。 |
| 龙卷龙 | 有可用素材及对方有效后场时才抢炸；已有响应时避免重复交。 |
| 励辉士 入魔蝇王 | 卡差和阶段由引擎判定；要能改善场面，且本回合伤害归零的代价可接受。已可斩杀时保留。 |
| 刻不知之杜加雷斯 | 默认抽二，优先丢后续可复活的调整。留手和当前急需场值时考虑苏生；翻倍用于可验证的斩杀窗口。分别记录下一回合跳过抽卡、主一或战阶。 |
| 闭锁世界的冥神 | 用对手怪作素材、入场批量擦和指定外抗性由引擎处理。墓地苏生康留给可结算的对手效果。 |
| 锁龙蛇 | 引擎按实际 2／3／4 个素材开放加攻、手牌特召和抽滤。优先洗回旧废牌，按当次留在手里的新抽牌计算。 |
| 龙骑兵团支配者·乔治 | 落地或对手特召时叫祭杖，持龙骑兵团装备才封墓。魔陷康送装备前考虑后续封墓，重复连锁有覆盖时保留。 |
| 水晶机巧·继承玻纤 棱镜 | 连接落地按素材等级调电磁虾；对手主阶段及战阶的衍生物用于防斩杀或回合结束后的资源，有更值钱的留场或已经用作乔治素材时保留。 |
| 龙魔导降灵师 | 优先墓地王女＋剑圣能融合女帝王的分支。引擎检查记名对象、墓地素材、额外自肃及回合结束恢复卡名。 |
| 交织绵羊 | 箭头里的特召和怪兽种类由引擎判断。优先把融合落在可用箭头并苏生 3／4 星调整。通常牌表只有融合、同调、超量的额外，仪式效果依赖对局额外资源。 |
