# 双子第三轮 Windows 试跑

实验目录为 Windows 训练机上的 `D:\codex-experiments\ygoat-twins-v3-pilot-20261126`。输入在 `inputs\guides.anchored.json`。最终结果在 `runs\pilot-anchored`，包含 36 个独立分片、模型、清单、汇总和复验记录。

在 Mac 的 SRVPro2 fixture 采集 12 手新起手的三种策略实盘。采样避开了前两轮训练、第二轮留出和混合对拍的起手。24 条回放实际吃到硬阻抗，共计 42 次。Windows 使用 6 个 CPU 工作进程，固定 36 条回放，每条最多 500 次探索、25 秒搜索预算。残局重新走完时，逐条核对实盘站位、终场分和对手抽牌数。

| 项目 | 结果 |
|---|---:|
| Windows 搜索及分片处理用时 | 140.4 秒 |
| 核对通过的实盘回放 | 36 / 36 |
| 实际结算到下回合的搜索路线 | 15290 |
| 有可比续接的决策窗口 | 2052 |
| 其中来自混合阻抗回放的窗口 | 1618 |
| 全部排序样本 | 4664 对 |
| 其中来自混合阻抗回放的样本 | 3759 对 |
| 离线验证排序准确率 | 73.7%（905 对） |
| 模型大小 | 1982 字节 |

先完整写出 6 个分片，再启动同目录续跑。续跑处理了剩余 30 条，前 6 个分片的 SHA-256 一致。另取两条各固定搜索 45 次，重复运行所得样本和模型逐字节一致。导出的模型在 WindBot 的 C# 评分器里加载通过，120 份局面与 Python 的推理值一致。

有 6 条回放核对通过但没有生成可训练排序对。混合回放的窗口数只统计存在不同合法动作且产生不同排序标签的分支。标签以终场分和对手实际抽牌为依据，这轮每额外给 1 抽扣 0.5 分。该分值是试跑参数。离线验证按双子起手分组，这轮评估以流程、样本产量和导出模型可用性为主。
